# Decem

Sohail's little-adventures page, born December 1st.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- Replace the hero photo in `public/my-pic-ghibli.jpeg` (or update the `src` in `src/app/page.tsx`)
- Edit vibe cards and lesson copy in `src/app/page.tsx`
